## 📌 Project Overview

This is an **interactive Power BI dashboard** that analyses mobile phone sales. It shows **sales, quantity and transactions** broken down by **city, brand and payment method**, so a sales manager can quickly see what is selling, where it is selling and how customers prefer to pay.

## 🎯 Business Questions Answered

| Question | Where to find it |
|---|---|
| What are the total sales, quantity sold and number of transactions? | KPI cards |
| Which brand is the top performer? | Brand wise charts |
| Which cities generate the most sales? | City chart and map |
| Which payment method is used the most? | Payment method chart |

## ✨ Dashboard Features

- 🔢 **KPI cards** for sales, quantity and transactions
- 📊 **Interactive charts** by city, brand and payment method
- 🗺️ **Map visual** to see sales by location
- 🎛️ **Slicers and cross filtering** so every visual updates when you click

## ⚙️ How I Built It

```text
Raw sales data  →  Clean in Excel  →  Power BI data model  →  KPI cards, charts, map  →  Insights
```

1. **Collect and clean:** gathered the sales data in Excel, fixed errors and prepared it for analysis.
2. **Model:** loaded the cleaned data into Power BI and set up the data model.
3. **Visualise:** built KPI cards, charts and a map, and added slicers for filtering.
4. **Tell the story:** summarised the top performing brand, top cities and most used payment method to support data driven decisions.
